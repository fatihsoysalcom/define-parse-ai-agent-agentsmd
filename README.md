# Define Parse AI Agent AGENTSmd

This example simulates the core concept of AGENTS.md by defining a simple AI agent's properties using a JSON-like structure. It demonstrates how a standardized, machine-readable format can be used to describe an agent's capabilities and interaction methods, fostering interoperability between different AI systems.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
